SUPPORT CENTRE

Help & Support

Learn how to use this workspace.

Getting started

Use the sidebar to navigate between farmers, farms, enumerators, visits, mapping, payments and reports.

Register farmers
Open Farmers and select Register Farmer. Add the farmer's name, contact and location.
Capture farm GPS
Add a farm, then use the GPS button when your device permits location access. Verify coordinates before saving.
Export data
Use CSV export buttons to open records in Excel-compatible software.
Before production
Connect Supabase, enforce role-based security, configure private photo storage and test backups. Do not store real bank details in the browser preview.
